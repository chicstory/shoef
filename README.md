# 👟 ShoeF (Shoes Finder) - 러닝화 위키 & 다나와식 실시간 최저가

> **러너를 위한 정품 러닝화 탐색기 (Shoes Finder)**  
> 도메인: [https://shoef.runanalyz.com](https://shoef.runanalyz.com)  
> 패밀리 서비스: [https://runanalyz.com](https://runanalyz.com) (러닝 분석 대시보드)

---

## 🌟 핵심 기능
1. **100% 실존 백화점/공식몰 PDP 다이렉트 랜딩**:
   * 가품 및 불량 셀러가 많은 쿠팡·오픈마켓을 철저히 배제하고 더현대 백화점 스마트스토어 등 검증된 화이트리스트 매장만 연동.
   * 단순 검색창이 아닌 실제 결제 및 옵션(사이즈) 선택이 가능한 고유 상품 상세 페이지(PDP) 직행.
2. **230mm~310mm 사이즈별 / 발볼(D, 2E, 4E)별 다나와식 최저가**:
   * 신발별, 사이즈별, 발볼별 실시간 가격, 정가 대비 할인율, 배송비 투명 비교.
3. **RunRepeat 공인 랩 테스트 스펙 연동**:
   * 실측 무게(g), 힐드롭(mm), 스택 높이(mm), 미드솔 폼 소재, 카본 플레이트 유무, 장단점(Pros & Cons) 수록.
4. **포레스트 그린(Forest Green) 테마 & 10대 브랜드 SVG 로고**:
   * 모바일 2열 스택 및 초슬림 슬라이딩 칩 UI로 한눈에 들어오는 가독성 제공.
